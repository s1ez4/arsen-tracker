# arsen-tracker

Игровой трекер прогресса на пути в пентест. Один файл `index.html`, без сервера.
Сайт: https://s1ez4.github.io/arsen-tracker/

## Что где править (всё в начале `index.html`, блок «НАСТРОЙКИ»)

| Что | Массив |
|---|---|
| Фразы дня | `PHRASES` |
| Лор (истории и шутки) | `LORE` — объекты `{ xp: 150, title: "…", text: "…" }`, xp = когда откроется |
| Мемы из папки `memes/` | `MEMES` — имена файлов, например `"kot.jpg"` |
| Стартовые слова | `START_WORDS` |
| XP за действия и куда кнопка перекидывает | `ACTIONS` — поле `url` |
| Вкладка «Ссылки» | `LINKS` |
| Уровни и награды | `LEVELS` |
| Чек-листы боссов | `BOSSES` |
| Порог кофе-штрафа (XP за неделю) | `COFFEE_MIN_XP` |
| Секретный лор (только на твоём компе, на GitHub не уходит) | `secret-lore.json` → потом `node tools/encrypt-secret.js` |
| Демотиваторы по прогрессу (можно со своими картинками) | `PROGRESS_MEMES` — поле `img: "файл.jpg"` из папки `memes/` |

## Как обновить сайт

```bash
git add .
git commit -m "Новые мемы"
git push
```

Через 1–2 минуты GitHub Pages покажет новую версию.

## Важно

Прогресс хранится в браузере (localStorage). Раз в неделю: «Экспорт прогресса» → сохранить JSON.
На новом устройстве: «Импорт прогресса» → выбрать этот файл.
